## Vamshi Portfolio

Modern portfolio site with a current resume on the home page and an archive page for older resumes.

## Features

- Responsive portfolio layout
- Dark mode toggle
- Resume download from the hero, navbar, and footer
- Separate resume archive at `/resumes`

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Resume Files

- Current resume: `public/resume.pdf`
- Archived resume: `public/resumes/legacy-resume.pdf`

## Project Structure

```text
src/
   app/
      layout.tsx
      page.tsx
      resumes/page.tsx
   components/
      Hero.tsx
      Navbar.tsx
      Footer.tsx
public/
   resume.pdf
   resumes/legacy-resume.pdf
```
